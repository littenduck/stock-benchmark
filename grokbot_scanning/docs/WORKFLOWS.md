## 数据管线 `scripts/run.py`

工作目录习惯：`cd /home/box/shared/stock-team/scripts`。

### 命令与参数

```
python3 run.py premarket            # 盘前（默认美东今天）
python3 run.py intraday             # 盘中
python3 run.py postmarket           # 盘后（默认会写 ledger.md）
python3 run.py postmarket --date 2026-11-16
python3 run.py postmarket --no-ledger
```

- 位置参数 `mode`：`premarket` | `intraday` | `postmarket`（必填）。
- `--date YYYY-MM-DD`：指定美东日期；K 线截到该日。期权链是抓取时的实时快照，回放历史日期时期权不对应该日，且不写 IV 历史。
- `--no-ledger`：不改 `ledger.md`。首席自己维护台账，所以首席三档都带这个开关。

路径解析：`scripts/lib/common.py` 里 `BASE = Path(__file__).resolve().parents[2]`，即「`scripts/lib/` 再向上两级」，在部署环境等于 `/home/box/shared/stock-team/`。它不把路径写成字面量硬编码，但约定 `lists.md`、`reports/`、`data/`、`ledger.md` 与 `scripts/` 同级。依赖：Python 3（本机为 3.13）+ pandas、numpy、requests。无券商接口。一次运行约 1–10 秒。

### 输入

- `lists.md` 的 `TICKERS`（只取 1x；杠杆 ETF 不扫描）。
- 若存在 AI 报告 `reports/<日期>/{macro,fundamental,technical,options,sentiment}.md`，解析评分/警报/置信度。
- 若存在 `reports/<日期>/<panel>.scores.json`（例 `{"MU": {"score": -1, "alert": "黄", "confidence": "中"}}`），优先于 markdown。
- 可选 `reports/<日期>/overrides.json`：人工覆盖脚本分，例 `{"macro": {"SOXX": -2}}`。

### 输出（均在 `reports/<日期>/`，除非另注）

- `summary-<mode>.md`：约 2–3KB。顺序：红色警报置顶 → 市场一行 → 每标的一行（价格、涨跌、宏/基/技/期/情分 → 短线总分[中线]、警报、六信号状态、支撑/压力、期权 1σ、相对上期变化）→ 黄色原因 → 说明 → 数据缺口。
- `summary-<mode>.json`：同内容机器可读版（含权重、来源、失效位、AI 分数对照）。
- `data/{technical,options,macro,fundamental,sentiment}-<mode>.json`：各面明细。
- `ledger.md`（仅盘后且未加 `--no-ledger`）：每标的新增一行；同日同标的重跑原地更新；旧行不删；满 5/20 个交易日回填涨跌，否则「无数据」。
- `/home/box/shared/stock-team/data/iv_history.csv`：每日平值 IV，满 20 天后算 IV Rank。

数据源：Yahoo chart / 期权链 / quoteSummary、FRED（`fredgraph.csv`，HY OAS=`BAMLH0A0HYM2`）、CNN 恐惧与贪婪。不调用 Robinhood。

各面脚本规则与「仍需 AI 判断」的部分见 `scripts/README.md`。加权：宏 20% / 基 25% / 技 25% / 期 20% / 情 10%；低置信减半、缺失或过期归零后按比例放大；财报 5 个交易日内技术面权重减半；情绪不能单独翻转方向；避险时总分上限 0；中线 = 宏观与基本面平均。
