# 盯盘团队数据管线（scripts/）

一次运行就抓完所有公开行情、算完五个面的数字评分和首席加权，输出一页摘要。AI bot 每档只需要运行脚本，读 `summary-<档>.md`（约 2–3 KB），再做下面“仍需 AI 判断”的部分。

## 用法
```
cd /home/box/shared/stock-team/scripts
python3 run.py premarket            # 盘前（今天，美东日期）
python3 run.py intraday             # 盘中
python3 run.py postmarket           # 盘后（同时写台账）
python3 run.py postmarket --date 2026-11-16   # 指定日期回放（K 线截到该日）
python3 run.py postmarket --no-ledger         # 不写台账
```
依赖：Python 3 + pandas / numpy / requests（已装）。一次运行约 2–10 秒。

## 输入
- `lists.md` 的 TICKERS（只取 1x 标的；杠杆 ETF 不扫描）。
- AI 报告 `reports/<日期>/{macro,fundamental,technical,options,sentiment}.md`：解析评分/警报/置信度。
  - 若某 bot 另写 `reports/<日期>/<panel>.scores.json`（`{"MU": {"score": -1, "alert": "黄", "confidence": "中"}}`），优先读它，更稳。
- 可选 `reports/<日期>/overrides.json`：AI 对脚本分数的人工覆盖，例 `{"macro": {"SOXX": -2}}`（比如政策头条）。

## 输出（`reports/<日期>/`）
- `summary-<档>.md`：红色警报置顶 → 市场一行 → 每个标的一行（价格、涨跌、宏/基/技/期/情分 → 短线总分[中线]、警报、六信号状态、支撑/压力、期权 1σ 区间、相对上期变化）→ 黄色原因 → 说明 → 数据缺口。
- `summary-<档>.json`：同内容的机器可读版（含权重、来源、失效位、AI 报告分数对照）。
- `data/{technical,options,macro,fundamental,sentiment}-<档>.json`：全部明细数字。
- `ledger.md`（仅盘后）：每个标的新增一行；同日同标的重跑会原地更新；旧行不删；满 5/20 个交易日自动回填涨跌，否则写“无数据”。
- `data/iv_history.csv`（团队根目录 data/）：每天的平值 IV，满 20 天后开始算 IV Rank。

## 各面的脚本规则
- **技术面（完全脚本化，评分与 AI 报告 10/10 一致）**：Yahoo 日线 2 年；MA20/50/200 及 10 日斜率、MACD(12,26,9)、RSI14、ADX14/±DI、布林(20,2)、ATR14、量比（÷前 20 日均量）、摆动点（左右各 3 根）、BOS/CHoCH（收盘越过已确认摆动点）、未回补日线 FVG、前日/前周高低、52 周高低。六信号与状态 A标准/A谨慎/过渡/B 按提示词。评分：状态 B=-1；且 ADX≥25、-DI>+DI、≥3 条同向证据（均线、MACD、DI、高低点序列）=-2；看多 2 个且 SMC 偏多=0（混合）；过渡=0；A 对称。盘中条件（穿 50/200 日线、日内±5%、量比>2、扫前日/前周高低）→黄。
- **宏观面（数字脚本化，与 AI 10/10 一致）**：VIX、VXN、^TNX、DXY、NDX/SPY/QQQ 距 200 日线（Yahoo）、HY OAS（FRED BAMLH0A0HYM2）、CNN 恐惧贪婪。逆风：10Y≥4.75% 或 20 日+20bp、VIX≥20、DXY 20 日+1.5%、HY 4 周+25bp；顺风对称。净逆风≥2 → -1；避险且偏空 → -2。半导体/存储额外 -1：SOXX 相对 QQQ 21 日落后>5pp 且 VXN-VIX>8。避险=（波动率高档、HY 4 周+50bp、NDX 在 200 日线下）≥2 项。
- **期权面（脚本代理，低置信，权重自动减半）**：Yahoo 期权链（盘后/夜间 Yahoo 的 IV 和 OI 常为占位，脚本用 Black-Scholes 由价格反解平值 IV；OI 明显为 0 时 PCR(OI)/最大痛点/持仓墙记无数据）。评分只看看跌看涨比（成交量、持仓量）的方向。黄：财报 5 个交易日内、IV 单日变化>10%、成交>5×持仓且权利金≥100 万。
- **基本面（数字）**：Yahoo quoteSummary：财报日、PE、远期 PE、PEG、营收/盈利增速、目标价、30 天 EPS 预期修正。脚本分只在没有 7 天内 AI 报告时使用（预期修正 >+3% → +1，<-3% → -1）。ETF 无脚本分。
- **情绪面（数字代理）**：恐惧贪婪 + 量比 + 涨跌：投降 / 过热迹象才给 ±1，否则 0；量比≥3 → 黄。1 个交易日内有 AI 情绪报告时用 AI 分。
- **首席加权**：宏 20% / 基 25% / 技 25% / 期 20% / 情 10%；置信度低权重减半，缺失或过期归零后按比例放大；财报 5 个交易日内技术面权重减半；情绪不能单独翻转方向；避险时总分上限 0；中线 = 宏观与基本面平均。红色 = 任一面评分较上期变 ≥2 档、收盘越过上期技术失效位，或 AI 报告自己标红；与上期相同的红色标“延续”。

## 仍需 AI 判断的部分
1. **情绪面**：X 搜索、Reddit/Stocktwits、韩国情绪、疑似操纵帖（脚本做不了）。建议每天盘后一次。
2. **基本面定性**：指引、行业周期、三情景估值、杀估值还是杀盈利。建议每周一次 + 财报后。
3. **宏观政策**：FedWatch 加息概率、出口管制/政策头条、海外市场、财报季整体。有事件时用 overrides.json 调分。
4. **期权面补充**：空头持仓、Form 4、13F、ETF 资金流、财报隐含波幅对比历史、GEX（需网页搜索），每周一次即可。
5. **首席**：冲突裁决文字、反方意见、杠杆 ETF（SPXL/TQQQ/SOXL/RAM）操作提示、命中率统计和推送决定。
6. 技术面 4 小时 / 1 小时 / 15 分钟的低周期确认、订单块、锚定 VWAP、成交密集区、斐波那契：脚本暂未实现（不影响评分）。

## 已知数据缺口
- 期权数据是抓取时的实时快照；用 `--date` 回放过去的日子时期权部分不对应那天（不写 IV 历史）。
- 夜间运行时 Yahoo OI 常为 0；盘中运行正常。
- HY OAS 有 1–2 个交易日滞后；Cboe VIX 期限结构、宽度（成分股站上 200 日线比例）未接入。
- 全程只读公开接口（Yahoo、FRED、CNN），不调用任何券商或交易接口。
